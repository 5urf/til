
## 커스텀 파이프 구현 방법

> [!NOTE]
> 커스텀 파이프를 구현할 때는 `PipeTransform` 인터페이스를 `implements` 해야 한다.
> 
> `PipeTransform`은 모든 파이프에서 구현해야 하는 인터페이스이며, 반드시 `transform()` 메소드를 정의해야 한다.
> 
> Nest.js는 컨트롤러 메소드로 향하는 인자(arguments)를 처리하기 위해 `transform()` 메소드를 호출한다.

```ts
import { ArgumentMetadata, PipeTransform } from '@nestjs/common';

export class BoardStatusValidationPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    return value;
  }
}
```

### transform() 메소드

해당 메소드는 두 개의 파라미터를 가진다.

* **value** : 현재 파이프라인으로 전달된 처리 대상 인자의 값이다. (예: 요청 본문 객체, 쿼리 값, 경로 파라미터 값)
* **metadata** : 현재 처리 중인 인자에 대한 부가 정보(메타데이터)를 담고 있는 객체다.
  * `type`: 인자가 어디서 왔는지 나타낸다 (`'body'` | `'query'` | `'param'` | `'custom'`).
  * `metatype`: 인자의 타입 정보를 나타낸다 (예: `String`, `CreateBoardDto` 등. 바닐라 JS이거나 타입 생략 시 `undefined`).
  * `data`: 데코레이터에 전달된 문자열 인자다 (예: `@Body('status')`라면 `'status'`).

`transform()` 메소드에서 반환(return)된 값은 다음 파이프나 최종 라우트 핸들러로 전달된다.

처리 도중 예외(Exception)가 발생하면 라우트 핸들러를 실행하지 않고 즉시 클라이언트로 에러 응답을 전송한다.

### value와 metadata 예시

컨트롤러에서 다음과 같이 파이프를 바인딩했을 때의 동작 예시

```ts
@Patch('/:id/status')
updateBoardStatus(
  @Param('id') id: string,
  @Body('status', BoardStatusValidationPipe) status: BoardStatus,
) {}
```

클라이언트가 `PATCH` 요청 본문으로 `{ "status": "private" }`를 보낸 경우:

* `value`: `'private'`
* `metadata`:
  ```ts
  {
    type: 'body',
    metatype: [Function: String],
    data: 'status'
  }
  ```

## 커스텀 파이프를 이용한 유효성 체크

게시글 상태(`status`) 값이 유효한 옵션인지 검증하는 커스텀 파이프 예시

```ts
import { ArgumentMetadata, BadRequestException, PipeTransform } from '@nestjs/common';
import { BoardStatus } from '../board.model';

export class BoardStatusValidationPipe implements PipeTransform {
  readonly StatusOptions = [
    BoardStatus.PRIVATE,
    BoardStatus.PUBLIC,
  ];

  transform(value: any, _: ArgumentMetadata) {
    value = value.toUpperCase();

    if (!this.isStatusValid(value)) {
      throw new BadRequestException(`${value} isn't in the status options`);
    }

    return value;
  }

  private isStatusValid(status: any) {
    const index = this.StatusOptions.indexOf(status);
    return index !== -1;
  }
}
```

### 코드 주요 포인트 설명

* **`readonly` 키워드**
  * 클래스 내부 멤버 변수를 읽기 전용으로 선언한다.
  * 런타임에 외부나 내부 메소드에서 `StatusOptions` 배열의 참조가 임의로 재할당되거나 수정되는 실수를 방지한다.
* **`BadRequestException`**
  * Nest.js에서 제공하는 기본 내장 HTTP 예외 클래스 중 하나다.
  * 호출 즉시 라우트 핸들러 진입을 차단하고, 클라이언트에게 HTTP 상태 코드 `400 (Bad Request)`과 함께 JSON 형식의 에러 응답을 반환한다.
