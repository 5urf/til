

>[!NOTE]
>효율적이고 확장 가능한 Node.js 서버 측 애플리케이션을 구축하기 위한 프레임워크
>
>TypeScript로 빌드되고 완벽하게 지원
>
>OOP(Object Oriented Programming), FP(Functional Programming)및 FRP(Functional Reactive Programming) 요소를 사용할수 있게 해준다

## Nest JS는 내부적으로 어떻게 구성되었나?

>[!NOTE]
>내부적으로  `Express`(기본값)와 같은 강력한 HTTP 서버 프레임워크를 사용하며,
>
>선택적으로 `Fastify`를 사용하도록 구성 할 수도있다
>
>일반적인 Node.js 프레임워크 위에 추상화 계층을 제공하는 동시에 개발자에게 해당 프레임워크의 API를 직접 노출한다 -> 이를 통해 개발자는 기본 플랫폼에서 사용할 수 있는 타사 모듈을 자유롭게 활용 가능


## Nest JS의 철학

>[!NOTE]
>Node를 위한 라이브러리, 도우미 및 도구가 많이 존재하지만 아키텍처의 주요 문제를 효과적으로 해결하지 못한다.
>
>-> Nest는 개발자 & 팀이 테스트 가능하고 확장 가능하며 느슨하게 결합되고 유지관리가 쉬운 애플리케이션을 만들 수 있는 즉시 사용 가능한 애플리케이션 아키텍처를 제공한다.
>
>이 아키텍처는 `Angular`에서 영감을 받았다.
